Simulación y análisis de señales con la Transformada de Fourier

Descripción del proyecto

Este proyecto tiene como objetivo simular y analizar señales en el dominio del tiempo y de la frecuencia mediante la Transformada Discreta de Fourier (DFT), utilizando la función FFT de Python.

Objetivos

Generar un pulso rectangular, una función escalón y una señal senoidal.

Visualizar las señales en el dominio del tiempo.

Calcular y representar los espectros de magnitud y fase.

Comprobar numéricamente las propiedades de linealidad y desplazamiento temporal.

Analizar el efecto de cambiar la frecuencia de una señal senoidal.

Tecnologías utilizadas

Python 3

NumPy

Matplotlib

Instalación

Instalar las dependencias con el siguiente comando:

python -m pip install -r requirements.txt

Ejecución

Ejecutar el programa con:

python main.py

Resultados esperados

El programa genera gráficas que permiten comparar las señales en el tiempo y sus respectivos espectros de frecuencia. También muestra resultados numéricos para las comprobaciones de propiedades de Fourier.
